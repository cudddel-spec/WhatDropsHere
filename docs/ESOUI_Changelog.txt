[size=4][b]0.3.0-beta[/b] (2026-11-07)[/size]
[list]
[*][b]English texts.[/b] English is now the default; the German client stays German. Other client languages show English.
[*][b]Display settings per character.[/b] Every character has its own display settings; you can copy the settings of another character in the menu. After the update, all characters start with your previous settings. The recorded data stays shared account-wide.
[*][b]Quality threshold per source type.[/b] Enemies, chests and containers, resources, critters and other, and theft each get their own threshold ("Off" or from which quality) – e.g. resources from green, enemies from purple. This replaces the previous on/off switches and the shared threshold. [b]/wdh_show[/b] sets the threshold for all enabled types.
[*]Loot windows without a name (e.g. the Dark Anchor reward chest): updates while taking items now belong to the same loot instead of being discarded as a nameless loot.
[*][b]/wdh_reset yes[/b] deletes the data in every language.
[/list]
